# mrjose_crea — Portfolio de José Gnimagnon (v3)

En ligne : https://mrjose-crea.vercel.app

Digital Marketer & Graphic Designer — Abomey-Calavi, Bénin.

Site statique (HTML, CSS, JavaScript), sans build. Thèmes clair et sombre.

## Fonctionnalités
- Thème clair / sombre (mémorisé, transition circulaire), suit le réglage du téléphone par défaut
- Hero avec pile de projets interactive
- Travaux choisis en défilement horizontal, index filtrable avec aperçu au survol
- Étude de campagne Facebook Ads avec graphique des vraies données
- Comparateur avant / après (retouche photo, affiche D-WEN)
- 11 études de cas avec galerie et visionneuse plein écran
- Formulaire qui prépare un message WhatsApp ou e-mail

## Structure
```
index.html        page unique
assets/img/       visuels (WebP)
assets/video/     vidéos (MP4)
vercel.json       en-têtes de cache
```

## Déploiement
Vercel : importer le dépôt, Framework Preset « Other », aucune commande de build.
